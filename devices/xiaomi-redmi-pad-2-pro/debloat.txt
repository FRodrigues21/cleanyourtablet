# Xiaomi Redmi Pad 2 Pro (25099RP13G, flute, flute_eea), HyperOS OS3.0.303.0.WPWEUXM, Android 16 (SDK 36), region PT
# Global/EEA ROM, Snapdragon 7s Gen 3 (SM7635), 6 GB RAM. Sold in some shops as "Redmi Pad Pro 2".
# Tested: 55 packages off, then reboot; Home, notifications, Settings, Wi-Fi and Play Store fine.
#
# Apply:   tools/pad.py disable devices/xiaomi-redmi-pad-2-pro/debloat.txt
# Undo:    tools/pad.py restore devices/xiaomi-redmi-pad-2-pro/debloat.txt
# HyperOS 3 refuses `pm disable-user` for every preinstalled system app ("SecurityException: Cannot
# disable system packages"), so most of these end up removed for user 0 instead (pad.py does this
# itself and records it); apps updated through the store (Notes, Weather, Calculator...) disable
# normally. Nothing is uninstalled from the system partition; restore brings everything back.
# Comment out any line you want to keep. Lines starting "# " + a package name are optional:
# uncomment the ones you don't use.
